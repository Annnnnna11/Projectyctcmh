## 2. pandas 术语与方法（最重要的一批，记住能读懂 80%）

### 2.1 数据结构

| 词 | 意思 |
|----|------|
| `DataFrame` | 二维表（有行有列），简称 df / frame |
| `Series` | 一列数据（一维） |
| `Index` | 行索引：每行的编号/标签。本项目是 `row_id` |
| `MultiIndex` | 多级索引（用多个列一起当键） |
| `CategoricalDtype` | 「类别类型」：类别列每行只存一个 int16 编码，省内存 |

### 2.2 读写文件

| 词 | 意思 |
|----|------|
| `read_csv` | 读 csv 文件成表 |
| `read_pickle` | 读 .pkl（把之前腌存的对象取回成表） |
| `to_pickle` | 把对象腌存成 .pkl 二进制文件（pickle=序列化保存） |
| `to_csv` | 写出成 csv |

### 2.3 取数据 / 选行列

| 词 | 意思 |
|----|------|
| `.loc[标签]` | 按「标签/条件」取行列，如 `grid.loc[grid["d"]<=1913]` |
| `.iloc[位置]` | 按「整数位置」取行列，如 `iloc[30490:]` |
| `.copy()` | 复制一份（避免改到原表的警告） |
| `.pop(列)` | 取出并删除某一列 |

### 2.4 变形 / 整理

| 词 | 意思 |
|----|------|
| `.groupby(键)` | 按键分组，之后常接聚合（sum/mean…） |
| `.agg(...)` | aggregate，分组后做聚合统计 |
| `.transform(...)` | 分组后算一个值再「广播回每一行」（行数不变） |
| `.merge(右表, on=键)` | 按 key 把两张表横向合并（类似 SQL join） |
| `.concat([表...])` | 把多张表拼接（沿行或列） |
| `.melt(...)` | 宽表转长表：把很多列(d_1…d_1941)「融化」成 一列天+一列值 |
| `.map(对照)` | 按「键→值」逐个替换（查表） |
| `.shift(n)` | 整体错开 n 行（做滞后特征 lag） |
| `.rolling(窗口)` | 滚动窗口（配合 mean/std 算移动统计） |
| `.astype(类型)` | 转换数据类型 |
| `.reset_index()` | 把索引变回普通列 |
| `.set_index(列)` | 把某列设为索引 |
| `.reindex(新索引)` | 按新索引重排/对齐（缺失填 NaN） |
| `.sort_index()` | 按索引排序 |
| `.rename(名)` | 改名 |

### 2.5 清洗 / 判断

| 词 | 意思 |
|----|------|
| `.dropna()` | 删除空值(NaN)行 |
| `.drop_duplicates(键)` | 去重 |
| `.unique()` | 取所有不重复的值 |
| `.isna()` | 判断是否为空值(NaN)，返回 True/False |
| `.all()` | 是否「全部」为 True |
| `.is_unique` | 索引是否无重复 |
| `.equals(别的)` | 两表/两索引内容是否**完全相等**，返回 True/False（比 == 更适合比整表） |
| `.clip(lower=0)` | 把小于 0 的截断成 0（防负方差） |
| `.where(条件, 否则值)` | 满足条件保留，否则替换 |
| `.pow(2)` | 求 2 次方（平方） |
| `.memory_usage()` | 占多少内存 |
| `.dt.day/.month/.year/...` | 从日期列提取 日/月/年/星期 等 |

### 2.6 顶层函数

| 词 | 意思 |

## 5. 自定义函数名（看动词前缀就能猜行为）

| 前缀 | 含义 | 本脚本例子 |
|------|------|-----------|
| `build_*` | 构造/生成某个东西 | `build_base_grid`（建基础网格）、`build_lag_table`（建滞后表）、`build_encoding_table`（建目标编码表） |

| `parse_*` | 解析 | `parse_stores`（解析要处理哪些门店） |
| `mark_*` | 标记 | `mark_complete`（标记为完成，写 metadata） |

## 附：目标编码公式（纯文本）

```
mean = total / count
std  = sqrt( (sumsq - total^2 / count) / (count - 1) )
```

- `mean/std` 只在第一遍 `aggregate_encoding_stats` 里算出，存进 `stats` 字典；
- 第二遍 `build_encoding_table` 只用 `map_stat` 按每行的键「查表回填」，不再做运算。
